# 2026_elixir
In this repository you can view the results of the 2026 Elixir "Step by Step" course. The topics were given but the codes are personal achievements.
URL: https://www.bioinformatics.hu/hu/node/206


## Ebolya Mayinga Survaillance [2026_ebola_survillance]
In this folder you can download the reference genom of Ebola mayinga virus and create the files needed to compare it with other Ebola mayinga sequences visually.

## RNA-Seq Analysis with the HiSat2 aligner [2026_UHR_BHR]
In this folder you can download the Universal Human Reference (UHR) genom and the Human Brain Reference (HBR). Makefile will help to create the files needed to visualize the alignments and visualize the coverages. Also with this makefile you will be able to do some basic statistic and export it to a csv file format.
